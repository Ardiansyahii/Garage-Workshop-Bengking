# Website Sistem Booking Bengkel (MVP)

Project ini dibuat menggunakan Next.js (App Router), Tailwind CSS, dan MySQL.

## Cara Menjalankan Project (Lokal):

1. **Siapkan Database:**
   - Buka Laragon/XAMPP, jalankan MySQL.
   - Buat database baru bernama `bengkel_db`.
   - Import file `bengkel_db.sql` ke dalam database tersebut.
   
2. **Install Dependencies:**
   Buka terminal di folder project dan jalankan:
   ```bash
   npm install
